# Aula 02 — HTML e CSS — Organização e Estilização de Páginas Web

**Professor da disciplina:** Me. Deivison S. Takatu

> Registro temático de revisão. A numeração possui finalidade organizacional e não representa uma aula oficial ou data confirmada.

## Resumo

O conteúdo apresenta a distinção entre a estrutura de uma página e sua aparência visual, destacando a organização de interfaces e sua adaptação a diferentes dispositivos. O repositório PW é uma referência proposta para relacionar esses fundamentos à prática.

## Objetivos de aprendizagem

- Compreender os fundamentos de HTML e CSS.
- Identificar a função dos elementos de marcação e das regras de estilo.
- Relacionar esses conhecimentos ao desenvolvimento e à manutenção de páginas web.

## Conteúdo principal

- HTML semântico: títulos, seções, formulários e botões.
- Atributos id e class para identificação e estilização.
- Seletores, cascata, especificidade e box model.
- Flexbox e Grid para organização visual.
- Viewport e media queries para responsividade.
- Acessibilidade com rótulos e elementos nativos.

## Aplicação prática e leitura técnica

O projeto PW pode ser utilizado como referência para localizar a estrutura HTML, as regras de CSS e a relação entre os elementos da página e seu comportamento visual. A análise deve identificar os arquivos existentes, os seletores utilizados e as técnicas de organização do layout.

O HTML define a estrutura do conteúdo, enquanto o CSS estabelece características como cores, fontes, espaçamento e posicionamento. Classes permitem aplicar estilos reutilizáveis; IDs identificam elementos individualmente.

Exemplo didático, não extraído do projeto:

```css
.card {
    padding: 16px;
    border-radius: 8px;
}
```

O DevTools permite inspecionar a marcação, os estilos aplicados e os recursos carregados pelo navegador.

## Metodologia e recursos

Leitura de código, consulta à documentação e exercícios de implementação.

## Atividades de revisão

1. Criar uma página com cabeçalho, conteúdo e rodapé.
2. Aplicar estilos aos cartões da interface.
3. Verificar a leitura em dispositivos com telas menores.
4. Inspecionar o HTML e o CSS do projeto e identificar os arquivos responsáveis pela interface.

As atividades são propostas de revisão, não tarefas oficiais atribuídas ao professor.
